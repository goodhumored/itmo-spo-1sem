# Лабораторная 1

## 1. Цели

Изучить средство синтаксического анализа и реализовать модуль для разбора текста в соответствии с языком по варианту. Реализовать построение синтаксического дерева с узлами, соответствующими элементам синтаксической модели языка. Вывести полученное дерево в файл в формате, поддерживающем просмотр графического представления.

## 2. Задачи

1. Изучить средство синтаксического анализа (Bison и Flex)
2. Изучить синтаксис разбираемого языка (вариант 1) и записать спецификацию для конструкций
3. Реализовать модуль, использующий Bison/Flex для разбора языка
4. Реализовать тестовую программу для демонстрации работоспособности
5. Оформить результаты тестирования в отчёт

## 3. Описание работы

### 3.1. Модули

Разработанная программа состоит из следующих модулей:

1. **lexer.l** - лексический анализатор (Flex), выполняет токенизацию входного текста
2. **parser.y** - синтаксический анализатор (Bison), строит AST на основе грамматики
3. **ast.h / ast.c** - модуль работы с абстрактным синтаксическим деревом (AST)
4. **main.c** - главная программа, координирующая работу парсера
5. **Makefile** - автоматизация сборки проекта

### 3.2. Способы использования

Программа запускается из командной строки с двумя аргументами:

```bash
./parser <input_file> <output_dot_file>
```

- `input_file` - файл с исходным кодом на разбираемом языке
- `output_dot_file` - выходной файл в формате DOT для визуализации дерева

Пример использования:

```bash
./parser test.src output.dot
dot -Tpng output.dot -o output.png
```

### 3.3. Примеры входной и выходной информации

**Пример входного файла (test.src):**

```c
int factorial(int n) {
    int result;
    result = 1;
    while (n > 1) {
        result = result * n;
        n = n - 1;
    }
}
```

**Пример выходного файла:** генерируется граф в формате DOT, который можно визуализировать с помощью Graphviz.

## 4. Аспекты реализации

### 4.1. Структуры данных для представления AST

Основная структура данных для представления узла дерева:

```c
typedef struct ASTNode {
    char *type;              // тип узла ("if", "varDecl", "literal", "binaryExpr")
    char *value;             // текстовое значение (имя переменной, оператор)
    struct ASTNode **children;
    int child_count;
} ASTNode;
```

Вспомогательные функции:

- `create_node(type, value)` - создание нового узла
- `add_child(parent, child)` - добавление дочернего узла
- `free_ast(node)` - рекурсивное освобождение памяти
- `print_dot(node, out)` - вывод дерева в формате DOT

### 4.2. Дополнительная обработка результата разбора

**Средство синтаксического анализа:** Bison 3.x с Flex 2.x

**Необходимая обработка:**

1. **Построение иерархической структуры выражений** - Bison по умолчанию строит линейное представление для выражений через приоритеты операторов. Для построения полноценного дерева были добавлены действия в грамматике, создающие узлы типа "binaryExpr", "unaryExpr" с соответствующими операторами и операндами.

2. **Управление памятью** - необходимо корректно освобождать память для строковых литералов и узлов дерева, создаваемых во время разбора.

3. **Обработка ошибок** - реализована функция `yyerror()` для вывода диагностических сообщений с указанием номера строки.

4. **Преобразование в формат DOT** - реализована рекурсивная функция обхода дерева и генерации графа в формате DOT для последующей визуализации.

### 4.3. Особенности реализации

**Лексический анализатор (lexer.l):**

- Распознает все типы литералов: строковые, символьные, шестнадцатеричные, битовые, десятичные, булевы
- Поддерживает ключевые слова языка (типы, управляющие конструкции)
- Игнорирует пробелы и комментарии
- Отслеживает номер строки для диагностики ошибок

**Синтаксический анализатор (parser.y):**

- Определяет приоритеты и ассоциативность операторов
- Строит AST через семантические действия в правилах грамматики
- Поддерживает все синтаксические конструкции из варианта 1:
  - Объявления функций с аргументами и возвращаемым типом
  - Операторы управления потоком (if-else, while, do-while, break)
  - Объявления переменных
  - Выражения с операторами всех типов
  - Вызовы функций и индексация массивов

**Модуль AST (ast.c):**

- Динамическое выделение памяти для узлов
- Динамический массив дочерних узлов с возможностью роста
- Рекурсивное освобождение всего дерева
- Генерация уникальных идентификаторов для узлов при выводе в DOT
